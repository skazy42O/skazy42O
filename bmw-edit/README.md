# BMW M5 G90 – mini edit

**Klip:** [`BMW_M5_G90_edit.mp4`](BMW_M5_G90_edit.mp4) – 1920x1080, **60 fps**, 30 s, H.264 + AAC 320k

- Muzika: Avmedov & Kedži – Beričet (deo 0:36–1:06), sve tranzicije i pucnji idu na ritam (117.5 BPM), drop = auto kreće
- Veliki tekst iz refrena iza auta/lika (YOLO segmentacija maske po kadru)
- Tranzicije: whip-pan sa motion blurom, zoom-through, spin, vertikalni whip, M-stripe (plava/teget/crvena) prelaz u poster
- Speed ramp + optical-flow slow-mo, shake, beat zoom pulsevi, chromatic aberration, color grade, grain, letterbox
- Plamen iz auspuha praćen na vrhovima auspuha (template tracking)
- Zvukovi auspuha: pravi snimci (Mercedes-AMG E63 / AMG GT V8, Jaguar F-Type crackles) iz
  [sathyaram/exhaustnotes](https://github.com/sathyaram/exhaustnotes) (izvor snimaka: @carlifestyle i drugi navedeni tamo)

`scripts/` – skripte kojima je klip napravljen (render.py = video, mix.py + master.sh = zvuk, sep.py/asr.py = tekst pesme).
